# Web Search 技能

当需要获取数据库之外的外部信息时使用，例如：宏观经济数据、政策新闻、行业动态、个股/ETF 相关事件。

## 使用方式

1. 调用 MCP 桥接工具 `web_search.search` 发起搜索
2. 查询参数尽量具体：包含时间范围、地域、主题词
3. 优先使用最新的搜索结果（注意当前日期）

## 注意事项

- 搜索结果是辅助信息，不替代本地数据库行情与策略数据
- 对搜索结果需做来源判断，官方渠道（政府/交易所/公司公告）优先
- 引用外部信息时注明来源，避免把搜索到的预测当作事实
