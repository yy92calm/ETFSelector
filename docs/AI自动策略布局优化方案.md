# AI自动策略页面布局优化方案

## 📊 当前问题分析

### 存在的问题
1. **内容过多** - 9个卡片纵向排列，页面过长
2. **优先级混乱** - 核心信息和辅助信息混杂
3. **功能分散** - 相关功能没有归类分组
4. **视觉疲劳** - 用户需要不断滚动才能看完所有内容

---

## 🎯 优化目标

1. **突出核心** - 策略状态和舆情数据放在最显眼位置
2. **逻辑分组** - 相关功能归类展示
3. **减少滚动** - 通过横向布局减少页面长度
4. **层次清晰** - 按优先级分层次展示

---

## 🎨 视觉优化建议

### 1. 颜色层次
- **第一层**：使用渐变背景，突出核心信息
- **第二层**：使用浅色背景，辅助分析
- **第三层**：使用警告色/安全色，突出风险
- **第四层**：可折叠，减少视觉干扰
- **第五层**：普通背景，历史记录

### 2. 尺寸控制
- **第一层**：占据屏幕顶部30%
- **第二层**：占据屏幕中部30%
- **第三层**：占据屏幕中下部20%
- **第四层**：可折叠，默认隐藏
- **第五层**：底部，可滚动查看

### 3. 交互优化
- **核心卡片**：始终可见，无需滚动
- **分析卡片**：自动刷新，无需手动操作
- **风险卡片**：异常时高亮提醒
- **舆情卡片**：可折叠展开
- **历史卡片**：底部，按需查看
