## 两种运行模式

### 模式一：自主决策（定时管道）

每个工作日由 APScheduler 触发，串行执行：

```
阶段1（确定性操作）
  ├── STEP 1: 更新ETF净值数据 (net_value_service)
  └── STEP 2: 组合再平衡 (portfolio_service)

阶段2（智能决策）
  ├── STEP 3: 舆情采集 (sentiment_service)
  └── STEP 4: LLM自主决策 (agent_core/loop.py)
              │
              ├── LLM可用 → AgentLoop.run_autonomous()
              │     感知(上下文) → 推理(LLM) → 行动(Tool Calling)
              │
              └── LLM不可用 → fallback 原有硬编码管道
                    AutoStrategyExecutor.run_all_auto_strategies()
```

**自主决策流程细节：**

1. `ContextBuilder` 构建系统状态摘要（活跃策略、市场涨跌幅、风控状态、最近AI决策）
2. 注入 system prompt，发送指令给 LLM
3. LLM 通过 Tool Calling 自主调用工具（查行情、检查风控、触发分析等）
4. 最多 10 轮工具调用，直到 LLM 给出最终结论
5. 决策结果记录到 `AIActionLog`，支持人工审批

### 模式二：人机对话（侧边栏交互）

用户通过前端AI侧边栏发送消息：

```
用户消息 → POST /api/chat
         → AgentLoop.run(message, session_id)
         → 多轮 Tool Calling 循环
         → 返回最终回复 + 工具调用记录
```

支持会话记忆持久化（ChatSession / ChatMessage），上下文连续。

## Agent Core 决策循环

核心文件：`app/agent_core/loop.py`

采用 **ReAct 模式**（Reasoning + Acting）：

```
┌──────────────────────────────────────────┐
│  1. 组装 system prompt + 上下文 + 消息    │
│  2. 调用 LLM（带 tools JSON Schema）      │
│  3. LLM 返回 tool_calls?                 │
│     ├── 是 → 执行工具 → 结果回填 → 回到2  │
│     └── 否 → 输出最终文本回复，结束        │
│  4. 安全阀：最多 MAX_TOOL_ROUNDS=10 轮    │
└──────────────────────────────────────────┘
```

**上下文注入（ContextBuilder）：**
- 活跃策略概况（名称、状态、配置比例）
- 市场概况（最新交易日涨跌幅 TOP3）
- 风控状态（熔断/回撤预警）
- 最近AI决策记录

## 多Agent辩论系统

### 分析辩论（Orchestrator）

文件：`app/agents/orchestrator.py`

```
阶段1: 数据消化
  ├── TechnicalAnalystAgent → 技术面报告
  └── SentimentAnalystAgent → 情绪面报告

阶段2: 多空辩论
  ├── BullResearcher → 看多论点
  └── BearResearcher → 看空论点

阶段3: 研究主管裁决
  └── MarketAnalystAgent → 最终判断
       输出: market_regime / suggested_action / suggested_allocation / confidence
```

### 风控辩论（RiskDebateOrchestrator）

文件：`app/agents/risk_agents/risk_debate_orchestrator.py`

```
前置检查（硬规则，不可绕过）:
  ├── 熔断触发 → 直接暂停策略
  └── 回撤临界 → 直接减仓

三方辩论（LLM驱动）:
  ├── AggressiveRiskAgent → 激进观点
  ├── ConservativeRiskAgent → 保守观点
  └── NeutralRiskAgent → 中性观点

裁决:
  └── RiskManager → 最终风控决策
       输出: proceed / reduce / stop
```

## 每周复盘

每周日 21:00 触发，对所有运行中的自动策略执行 `ReviewService.trigger_review()`，生成周度绩效复盘报告。

## 降级与容错

- LLM API Key 未配置 → 自动降级为原有 `AutoStrategyExecutor` 硬编码管道
- LLM 调用异常 → 捕获异常后 fallback
- 多Agent辩论中单个Agent失败 → 记录warning，不阻断整体流程
- 风控硬规则（熔断/临界回撤）优先于LLM辩论结果，不可被覆盖
- 工具执行结果超过3000字符自动截断，防止token溢出
