# 市场状态刻画与仓位信号方案（第一期）

## 背景

投资研究框架分三层：仓位（风险偏好+分化度→中期权益仓位）、行业（盈利-估值性价比捕捉行业β）、标的（成长-估值匹配）。本期落地**市场状态刻画与仓位信号**（框架第1条+仓位层面）；行业与标的层的盈利-估值模型依赖 PE/PB 历史估值数据源（baostock，需新增依赖）与行业分类表，留作二期。

## 可行性结论

- 风险偏好/风格轮动：现有 `ETFQuotation` 日K即可算（代理ETF组价差+热度+波动分位）
- 基金收益率分化度：efinance 0.5.8 已装，`fund.get_fund_codes('gp'/'hh')` 拿名单 + `get_quote_history_multi` 批量净值
- 不引入 akshare（云端未装，两融/涨跌停等留二期随数据源一起做）

## 设计

### 数据层（app/services/data_sources.py）
`EFinanceDataSource.fetch_fund_nav_batch(fund_codes, pz=80)`：`ef.fund.get_quote_history_multi` 批量净值，有效样本不足时抛错触发退避重试+熔断；`DataSourceManager` 同名分发（沿用主备模式，此数据仅 efinance 有）。

### 模型（app/models/market_regime.py，注册 init_db）
`MarketRegimeSnapshot`：trade_date(唯一)、risk_appetite(0-100)+risk_label、style_rotation(JSON: 大小盘/成长价值占优与价差)、fund_dispersion+dispersion_label、market_state(state/label/note)、suggested_equity_range(JSON)、details(JSON 各分量)。

### 服务（app/services/market_regime_service.py，单例）
- **风险偏好**（0-100）：高beta组(512880/159915/588000)20日动量 − 防御组(511010/511260/511020/518880/518850/159934) → `50+价差×2.5` 占 60%；全池日成交额250日分位 25%；全池平均20日波动率的250日分位（低波加分）15%。标签 <35 保守 / <65 中性 / ≥65 进取。代理代码无数据自动跳过。
- **风格轮动**：大盘(510050/510300/510500) vs 小盘(512100)、成长(588000/159915) vs 价值红利(510880) 的20日动量差，|价差|>3% 判占优。
- **收益率分化度**：偏股基金(gp+hh)固定种子抽样100只，近60日累计净值收益截面标准差；<8% 一致（β行情）/ 8-15% 适度 / >15% 分化（α行情）。样本<30 只当日缺省。
- **仓位建议**：进取+一致→70-90%；进取+分化→60-80%；中性→40-70%；保守→10-40%。
- **市场状态**：进取+低波动→机会；保守→风险；其余中性，note 说明各维度组合逻辑。
- `compute(trade_date, db)` 幂等（先删后插）；`get_latest/get_history`。

### 管道（scheduler.py + task_routes.py）
新阶段 `market_regime` 插在 `market_scan` 之后（指标已就绪）、`rotation_review` 之前；`PIPELINE_STAGES` 加元数据，任务视图步骤条自动获得；检查点/失败经验复用 `_run_stage`。

## 二期：盈利-估值性价比模型（已实现）

**数据层**：`fundamental_data_service.py` 封装 baostock——池=沪深300+中证500（800只），日频估值（peTTM/pbMRQ）、季度增速（YOYNI，按披露节奏取最近两个应已披露报告期）、行业分类（证监会行业，回填时全量拉取）。落库 `stock_fundamental`（code+date 唯一，增速冗余进行）。

**模型层**（`value_model_service.py`）：
- 行业性价比：行业中位 PE / 中位增速 / PEG（中位PE÷中位增速）+ 中位PE历史分位（约2年）+ 产业趋势（行业ETF关键词匹配的20日动量）；得分 = 0.5×性价比（PEG低+PE分位低）+ 0.3×增长 + 0.2×趋势，样本<5 的行业不参评。
- 个股安全边际：盈利正增长且 PEG≤1.5 候选；得分 = 0.6×PEG分 + 0.4×自身PE历史分位反分（历史<30样本时取中性50）。
- 管道阶段 `fundamental`（每日增量5天）；手动回填 `POST /api/research/backfill?years=3`（后台线程，含增速与行业全量刷新，约15-25分钟）。
- 前端"研究"视图：个股安全边际榜 + 行业性价比排名。

**已知局限（后续迭代方向）**：
- 低基数导致的极端增速（扭亏为盈、增速数千%）会让 PEG 趋近 0 而霸榜，可考虑增速封顶（如按 100% 计）或要求连续多季增长；
- 周期股"高增长+低PE"组合可能处于景气顶部（PE分位 0 反而危险），PE 分位应结合盈利所处周期位置解读；
- 行业口径为证监会分类（baostock 提供），与申万/东财板块存在差异；产业趋势代理为关键词匹配的行业 ETF，覆盖不全的行业无趋势分。
