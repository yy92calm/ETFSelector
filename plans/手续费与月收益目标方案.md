# 手续费与月收益目标方案

## 需求

1. 每次调仓操作收取手续费：单笔买卖金额的 0.5%，最低 10 元（老杨确认，原话"5%"实为 0.5%）
2. 策略核心目标：月收益 5%-10%。调仓/保持/减仓等操作须围绕该目标展开，通过"AI提示词注入 + 程序化进度检查"落地

## 现状对照

| 项 | 现状 | 目标 |
|----|------|------|
| 手续费 | 无。`compute_adjustment` 现金变动=纯成交额 | 单笔 `max(金额x0.5%, 10元)` |
| 交易记录 | `TradeRecord` 无费用字段 | 增加 `fee` 字段 |
| 回测成本 | 无成本模型 | 统计 `total_commission`，逐日卡片显示 |
| 收益目标 | 策略表无目标字段，AI无目标概念 | `target_monthly_min/max` 字段 + 提示词 + 进度检查 |

## 关键约束

- `compute_adjustment` 为回测与实盘共用（AGENTS.md），费用逻辑集中于此，两边同时生效、同时验证
- 新字段通过 `init_db()` 内 ALTER TABLE 兼容，不引入 Alembic
- 费率走 `config.py` Settings（`COMMISSION_RATE=0.005`、`COMMISSION_MIN=10.0`），可 .env 覆盖
- 月收益进度检查只读 `PortfolioSnapshot`，不新增写库路径

## 模块结构

```
app/config.py                    + COMMISSION_RATE / COMMISSION_MIN
app/strategies/base.py           compute_adjustment 计费，返回 fee
app/models/strategy.py           + target_monthly_min / target_monthly_max
app/models/portfolio.py          TradeRecord + fee 字段
app/db/database.py               init_db ALTER TABLE 兼容
app/services/backtest_service.py 汇总 total_commission；adjustment 记录 fee
app/services/portfolio_service.py 实盘扣费 + get_monthly_progress()
app/agents/orchestrator.py       分析前计算月进度，传入裁决与风控
app/agents/market_analyst.py     PROMPT 注入目标与进度
app/routes/backtest_routes.py    响应透传（无改动则跳过）
static/js/workbench.js           回测统计+总手续费；策略卡月进度条
```

## 月进度定义

- 当月收益 = 最新快照总资产 / 当月首个快照总资产 - 1
- 目标节奏 = 下限5% x 已过交易日 / 当月总交易日（线性推进）
- 状态判定：
  - 落后（behind）：当月收益 < 目标节奏
  - 达标（on_track）：节奏 <= 收益 <= 节奏x2 且 < 10%
  - 超额（above）：当月收益 > 10%（提示落袋防守）
- 进度文本示例："本月收益2.1%，目标节奏4.5%，状态：落后"

## 提示词注入内容（market_analyst 裁决 + 风控辩论）

```
【策略核心目标】月收益5%-10%（年化约70%-226%，属高风险高波动目标）。
【当前进度】{月收益}，目标节奏{节奏}，状态：{落后/达标/超额}。
要求：
- 落后时优先提高权益暴露的进攻性，但不得突破风控上限；
- 达标时维持当前配置，减少无谓调仓（每次调仓有0.5%手续费+10元最低成本）；
- 超额时逐步兑现收益、增配防御资产，保护既有收益。
- 调仓建议须权衡预期收益改善是否覆盖交易成本。
```

## 实施步骤

1. 费率配置 + compute_adjustment 计费 → 验证：单元测试（买10万费500、买1000费10、卖出现金=金额-费）
2. 模型字段 + ALTER TABLE → 验证：重启后 PRAGMA 确认列存在
3. 回测/实盘接入费用 → 验证：同区间回测前后对比，收益应下降且 total_commission>0
4. get_monthly_progress → 验证：用 8 月真实快照手工核对收益率
5. 提示词注入 → 验证：跑一次分析，analysis_result 含 monthly_target_status
6. 前端展示 → 验证：Playwright 截图

## 风险与说明

- 0.5% 双边费 + AI 当前"天天调仓"习惯：回测收益将显著承压，这正是摩擦模型的目的（逼出"调不调值得吗"的克制）；若过重可调 .env
- 月收益 5% 起步目标偏高，样本期 AI 大概率长期处于"落后"状态；提示词已要求"不得为追目标突破风控"，避免激进赌方向
- 回测引擎的规则驱动模式（rule_engine）暂不感知月目标（它是确定性映射），第二阶段接入 AI 规则表时一并处理
