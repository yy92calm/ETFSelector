# 板块轮动到选型方案（借鉴 open-ai-workbench 宏观洞察）

## 背景与问题

现有策略是**单层选型**：全市场 ETF 按 5 维综合分排名 → 与持仓比分数差距（≥5 分）→ 轮动辩论 → 换仓。
板块层只有 `value_model_service` 的「行业盈利-估值性价比」，存在三个硬伤：

1. **覆盖窄**：只能统计沪深300+中证500 成分股（证监会行业口径 34 个），部分行业仅 1 只样本（线上实测「组内样本 1 只」）
2. **只有估值、没有行情**：没有板块动量 / 相对强度 / 成交热度，无法回答「资金正在流向哪个板块」
3. **不参与选型**：板块信号仅作为 `industry_value` 注入辩论材料，候选筛选阶段完全不看板块

结果：选型可能买入「低配板块里的强势个券」——个券动量强但板块在系统性走弱。

## 借鉴来源（桌面项目 open-ai-workbench「宏观洞察」）

| 可借鉴项 | 内容 |
|---|---|
| 数据源 | 申万宏源官网公开接口：31 个一级行业实时行情 + 逐日分析（收盘/涨跌幅/换手/PE/PB/股息率/成交额占比/流通市值），免 key |
| 评分模型 | `score = 100×(0.45×相对强度分位 + 0.35×60日动量分位 + 0.20×趋势)`，相对强度 = 行业 60 日收益 − 沪深300；≥67 超配 / ≤33 低配 |
| 工程口径 | 发布滞后时以「覆盖 ≥28 家的最新日期」为截止日；成交额占比合计≈100% 自校验；失败独立降级 |
| 展示形态 | 31 行全景表（今日/成交占比/换手/PE/股息/60日/评分/信号）+ 明细下钻 + 注入 prompt |

## 设计

### 1. 数据层（新外部源，独立降级）

- `app/services/sw_industry_service.py`：
  - 抓取：`index_publish/current`（实时行情）+ `index_analysis/index_analysis_report`（120 天窗口，单请求）
  - **TLS**：swsresearch 只回叶证书，Python/Ubuntu 默认握手失败（本机与服务器均已实测）→ 仓库内置中间证书 `app/resources/certs/`，运行时 certifi+中间证书合成 bundle；浏览器 UA 必需（无 UA 返回 508）
  - 解析：纯函数（字符串数字容错、空值→None），`common_cutoff` 取覆盖 ≥28 家的最新日期
- 新表 `sw_industry_daily`（trade_date + sw_code 唯一）：close / markup / turnover_rate / pe / pb / dividend_yield / amount_share / float_mcap + 计算列 ret60 / rs60 / trend / vol60 / score / signal / score_delta
- 基准：相对强度基准用现有 `510300`（沪深300ETF）收盘序列，避免再引入指数行情源；缺失时 rs60=None（该行不评分）

### 2. 板块评分模型（照搬口径）

`score = 100×(0.45×percentile(rs60) + 0.35×percentile(ret60) + 0.20×trend)`，≥67 超配 / ≤33 低配 / 其余中性；
`score_delta` 与前一交易日比较；`vol60 ≥ 45%` 标注高波动（仅展示）。

### 3. 板块 → 选型（两段式）

新增 `app/services/sector_selection_service.py`：

```
申万板块评分（31） → 超配板块（≥67）
   ↓ 板块 → ETF 关键词映射表（31 行业，如 电子→半导体/芯片/消费电子）
   ↓ 板块内按 ETF 5 维综合分排名 → 每板块取 Top N
候选池（带板块归属 + 板块评分/信号）
   ↓
轮动辩论材料（板块上下文）+ 自主决策工具 get_sector_rotation + 策略依据面板
```

- 持仓若属低配板块（≤33）→ 在辩论材料中标注「板块逆风」，与候选板块对比
- 选型仍以 ETF 5 维综合分为主，板块为**分层依据**（强度见下方待确认项）

### 4. 管道

新增阶段 `sw_sector`（`market_scan` 之后、`fundamental` 之前）：抓取+落库+评分，独立检查点与 TaskExecutionLog 记账，失败不中断管道（沿用现有降级到最近已落库数据）。

### 5. 展示

- 研究视图新增「申万一级行业全景」区块：31 行表（行业/涨跌/成交占比/换手/PE/股息/60日/评分/信号）+ 本策略标的 chips
- 策略视图「决策依据 → 研究依据」卡升级：每只标的显示所属申万板块 + 板块评分/信号/PE，候选显示板块归属
- 新只读工具 `get_sector_rotation`；自主决策 prompt 增加板块层要求

## 实施与验证（2026-09-25）

- 数据源实测：本机 31 行业 / 82 个交易日 / 成交占比合计 100.0%；服务器可连通但证书链需内置中间证书（`app/resources/certs/`）
- 落地：`sw_industry_daily` 表（15 文件 23 表）+ `sw_sector` 管道阶段（11 阶段）+ `get_sector_rotation` 工具（只读，共 47 个工具）
- 实测结果（本地）：截止日 2026-09-23，31 行业，超配 8 / 低配 11；策略持仓 518850 黄金→有色金属 低配31（逆风）、515050 通信→通信 低配30（逆风）——板块层已能识别持仓的板块逆风
- 单测 19 项（解析/截止日回退/评分分档/长词优先映射/信号反查/半硬分流/模式关闭/失败降级/依据段/工具注册）+ 全量 217 passed
- 浏览器实测 7/7：研究视图申万全景表 31 行与策略标注、依据面板超配/低配板块与标的板块行

## 风险与边界

- 申万接口无 SLA；发布滞后（当日部分行业次日补齐）→ 截止日口径 + 独立降级
- TLS 链不完整 → 内置中间证书；CA 轮换时需更新该文件（失败则该源降级，不影响既有管道）
- 板块-ETF 映射是关键词近似（宽基/跨行业 ETF 可能无法归类）→ 未命中标注「未匹配板块」，不参与板块层约束
