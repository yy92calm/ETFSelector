# 首页密码校验方案

## 需求

访问首页需输入密码 `test@123`，验证通过后才可进入主页面。

## 实施步骤

### 1. 后端

- 新建 `app/routes/auth_routes.py`
  - `POST /api/auth/login`：校验密码，返回 token
  - `GET /api/auth/check`：检查当前 token 是否有效
- `app/__init__.py`：加中间件拦截所有 `/api/*` 请求，校验 Authorization header 中的 token（白名单：`/api/auth/login`、`/health`）
- Token 用简单 HMAC 签名，服务端校验

### 2. 前端

- `index.html` 和 `workbench.html`：加登录遮罩层，未登录时显示密码输入框
- 登录成功后 token 存 localStorage，后续 fetch 请求自动带 Authorization header
- 退出登录清除 token

### 3. 验证

- 访问首页 → 显示密码输入框
- 输入错误密码 → 提示错误
- 输入正确密码 → 进入主页面
- 刷新页面 → 已登录状态保持
- 清除 localStorage → 需重新登录
