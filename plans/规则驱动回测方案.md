# 规则驱动回测方案（第一阶段）

## 现状对照

| 维度 | 当前 | 目标 |
|------|------|------|
| 回测模式 | 静态配置（整个区间同一套allocation_config） | 规则驱动（每日根据技术指标动态调整配置） |
| 数据来源 | Strategy.allocation_config（固定） | etf_quotation + etf_daily_indicator（逐日计算） |
| 覆盖范围 | 仅限策略已运行天数 | 2020-2026全量行情 |
| 引擎改造 | 无 | PortfolioContext支持逐日不同allocation_config |

## 关键约束

1. **数据获取频率控制**：efinance批量拉取需间隔≥2秒，避免被封IP
2. **技术指标计算**：复用现有`TechnicalIndicatorService`，不重复造轮子
3. **回测引擎改造**：最小侵入，不破坏现有静态回测功能
4. **前端交互**：在分析Tab增加「回测此规则」按钮，一键触发

## 数据流

```
etf_quotation (2020-2026, 21.6万条)
    ↓ 批量计算（每日266只ETF）
etf_daily_indicator (补全后约12万条)
    ↓ RuleEngine 逐日读取
市场状态判定 (regime, trend, volatility)
    ↓ 查规则表
当日 allocation_config
    ↓ 注入 BacktestEngine
动态回测结果
```

## 接入点

### 1. RuleEngine（新增模块）

路径：`app/services/rule_engine.py`

核心函数：
```python
class RuleEngine:
    def compute_daily_allocation(
        self, 
        trade_date: date, 
        db: Session,
        base_allocation: dict,  # 默认配置（fallback）
        strategy_profile: str = "balanced"  # balanced/aggressive/conservative
    ) -> dict:
        """根据当日技术指标计算目标配置"""
```

市场状态判定逻辑（确定性规则，非LLM）：
- **趋势判断**：取权重最大的3只ETF，若>MA20且动量5d>0 → 偏进攻；否则偏防御
- **波动判断**：若20日波动率>25% → 降低权益仓位10%
- **动量判断**：若市场平均动量20d>3% → 加仓动量ETF；<-3% → 减仓

规则表（硬编码，后续可从AI历史训练替换）：
```python
RULES = {
    "bull_strong": {"equity_weight": 0.85, "bond_weight": 0.10, "gold_weight": 0.05},
```

### 2. BacktestEngine 改造

路径：`app/services/backtest_service.py`

改造点（第101-110行）：
```python
# 当前（固定配置）
ctx = PortfolioContext(
    ...
    allocation_config=strategy.allocation_config,  # 固定
    ...
)

# 改造后（支持动态配置）
if mode == "rule_based" and rule_engine:
    daily_alloc = rule_engine.compute_daily_allocation(td, db, strategy.allocation_config)
else:
    daily_alloc = strategy.allocation_config
ctx = PortfolioContext(
    ...
    allocation_config=daily_alloc,  # 逐日变化
    ...
)
```

### 3. API 改造

路径：`app/routes/backtest_routes.py` + `app/schemas/schemas.py`

BacktestRequest 新增字段：
```python
class BacktestRequest(BaseModel):
    strategy_id: int
    start_date: date
    end_date: date
    initial_capital: Optional[int] = None
    mode: str = "static"  # "static" | "rule_based"
    strategy_profile: str = "balanced"  # "balanced" | "aggressive" | "conservative"
```

### 4. 前端对接

在 `static/js/workbench.js` 的分析Tab增加按钮，点击后：
1. 调用 `POST /api/backtest/run` 传入 `mode: "rule_based"`
2. 使用分析Tab的日期范围作为回测区间
3. 展示回测结果曲线
