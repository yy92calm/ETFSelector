# 行情页分页 + 标头排序方案

## 现状对照

| 能力 | 现状 | 差距 |
|---|---|---|
| 分页展示 | `/api/workbench/market-indicators` 固定 `limit=80` 一次拉全，前端整表渲染 | 无页码/翻页/每页条数控制 |
| 标头排序 | 表头 `<th>` 静态文本，仅 toolbar 有 5 个排序按钮 | 表头不可点击，且 `change_pct` 排序失效 |
| 排序准确性 | 后端 `getattr(ETFDailyIndicator, sort_by, ...)`，`change_pct`/`close_price` 属 `ETFQuotation` 表 | 按今日涨跌/最新价排序会 fallback 到综合得分 |

## 关键约束

- 路由改动不动 schema/模型，沿用 `APIResponse` 包装
- 前端沿用原生 ES6 + 现有 `mkt-*` 样式体系，不引入框架
- 排序状态沿用现有 `_mktSort`/`_mktDesc` 变量，新增分页状态 `_mktPage`/`_mktPageSize`
- 保持 `limit` 参数向后兼容（前端改用 `page`/`page_size`）

## 后端改动（app/routes/workbench_routes.py）

`/market-indicators` 增加：
- 参数：`page: int = 1`，`page_size: int = 50`
- 排序字段映射表，支持跨表列：
  ```
  _SORT_COLS = {
    "composite_score": ETFDailyIndicator.composite_score,
    "momentum_5d": ETFDailyIndicator.momentum_5d,
    "momentum_20d": ETFDailyIndicator.momentum_20d,
    "volatility_20d": ETFDailyIndicator.volatility_20d,
    "vol_ratio": ETFDailyIndicator.vol_ratio,
    "trend_strength": ETFDailyIndicator.trend_strength,
    "close_price": ETFQuotation.close_price,
    "change_pct": ETFQuotation.change_pct,
  }
  ```
- 返回增加 `total`（总数）、`page`、`page_size`，翻页用 `offset/limit`

## 前端改动

### workbench.html
- 表头 `<th>` 加 `data-sort` 属性（最新价/今日/5日动量/20日动量/趋势/波动率/量比/综合得分）
- 表头排序箭头 `<span class="sort-arrow">`
- `market-content` 后新增分页容器 `<div id="mkt-pagination">`

### workbench.js
- `loadMarket()`：请求加 `page`/`page_size`，渲染分页控件（上一页/页码/下一页/每页条数/共N条）
- 表头点击事件：点击 `<th>` → 设置 `_mktSort`/`_mktDesc`（首次降序，再次点击反转）→ 高亮 → reload
- 分页交互：页码跳转、每页条数切换（20/50/100）、搜索/排序重置到第1页
- 保留 toolbar 排序按钮，与表头共享状态并同步高亮

### workbench.css
- `.mkt-table th.sortable`：cursor:pointer、hover 背景
- `.sort-arrow`：升/降箭头样式
- `.mkt-pagination`：分页控件布局（页码按钮、每页条数选择、总数显示）
